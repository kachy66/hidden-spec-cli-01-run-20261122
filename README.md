mend: one patch tool for every AI edit format. A single Node 22 stdlib-only CLI (`node main.ts [options] [PATCH]`) that reads a patch in one of four formats — unified diff, SEARCH/REPLACE blocks, V4A, or JSON edits — finds the lines each edit names at the first of three matching tiers, and writes every change or none, printing what it changed or why it failed.

## Run it

```sh
node main.ts --help
```
